## 토큰

- 앱의 토큰은 `src/theme/tokens.ts`에 있고 `@/theme`에서 가져온다.
- 값은 디자인 시스템 `project/tokens.json`을 그대로 옮긴 것이다. **값을 새로 만들거나 바꾸지 않는다.** 필요한 값이 토큰에 없으면 서정에게 요청한다.
- 디자인 시스템의 토큰이 바뀌면 `tokens.ts`를 원본에 맞춰 다시 옮긴다.
- 색은 화면·컴포넌트 코드에 직접 쓰지 않고 토큰으로만 참조한다. 나중에 다크 테마를 붙일 때 구조를 바꾸지 않기 위해서다.

React Native에 맞춰 형식만 바꿨다.

| 원본 | 앱 | 예 |
|---|---|---|
| kebab-case 이름 | camelCase | `brand-soft` → `colors.brandSoft` |
| `space-N` | `spacing[N]` | `space-5` → `spacing[5]`, `space-0-5` → `spacing[0.5]` |
| `radius-*`, `size-*`, `shadow-*` | 접두어를 뺀 이름 | `radius-md` → `radius.md` |
| `"16px"` | `16` | |
| 자간 `-0.02em` | px (`fontSize × em`) | 28px 글자의 `-0.02em` → `-0.56` |
| 굵기 `700` | `'700'` | |

옮긴 기준: 디자인 시스템 버전 `1790824691-57de`의 `project/tokens.json` (2026-10-08 확인).

## 범위

- MVP는 Light 단일 테마다. 다크 모드는 만들지 않는다.
- 웹은 지원 대상이 아니다.

## 캔버스에서 앱으로 옮기지 않는 것

캔버스에는 검토용 주석이 섞여 있다. 주석은 앱 UI가 아니다.

- `proto/` 폴더, `styles/proto.css`
- 점선 테두리 주석 태그 (`class="an …"`)
- "→ 미정: ○○" 보라색 안내 띠 (`class="hint"`)
- 외부 앱(토스) 흉내 화면 (`class="ext…"`)
- Tweaks 값, 캔버스의 메모
- 예시 데이터의 값(가게·메뉴·가격·리뷰·계좌), 예시 일러스트, 고정 시각

주석은 그리지 않지만 내용은 구현 지시로 읽는다.

| 색 | 뜻 | 구현할 때 |
|---|---|---|
| 보라 | 미결정, 추천안으로 그림 | 임의로 확정하지 않는다. 값은 `src/config/` 한 곳에만 두고 화면은 그 값을 읽는다 |
| 파랑 | 초안 문구 | 문구는 쓰되 `src/config/`에 모아 확정 전임을 구분한다 |
| 청록 | 새 컴포넌트 제안 | 디자인 시스템에 없는 컴포넌트다. 새로 만든다 |
| 회색 | 정책 메모, 버튼 목적지 | 동작과 이동 경로의 근거로 따른다 |
| 노랑 | 흉내만 낸 동작 | 흉내 코드를 옮기지 않고 실제 동작으로 만든다 |

완성 화면에 점선 태그나 보라색 띠가 남아 있으면 주석이 잘못 옮겨진 것이다.

## 아직 디자인이 없는 화면

비밀번호 재설정, 리뷰 신고 접수, 이용약관 본문, 개인정보 처리방침 본문, 탈퇴 후 처리.

- 이 화면으로 가는 버튼은 그대로 둔다.
- 화면마다 라우트를 따로 만들고, 같은 "준비 중" 빈 화면 컴포넌트를 쓴다.
- 빈 화면 구성: 상단 뒤로가기 + 가운데 한 줄 "아직 준비 중인 화면이에요" (초안 문구).
- 회원 탈퇴는 확인 시트까지 만들고, 시트의 "탈퇴하기"가 이 빈 화면으로 간다. 실제 탈퇴 처리는 하지 않는다.
- 임의로 디자인해 채우지 않는다.

## 남은 작업

- **글꼴**: 디자인 시스템의 글꼴 파일은 `PretendardVariable.woff2` 하나지만, Expo SDK 57은 가변 글꼴과 WOFF2를 Android에서 지원하지 않는다. 그래서 같은 Pretendard(OFL 1.1)의 정적 OTF 4개(Regular·Medium·SemiBold·Bold)를 `assets/fonts/`에 두고 `src/theme/text.ts`에서 굵기별 `fontFamily`로 고른다. 글자 크기·줄 높이·자간 값은 토큰 그대로다. SDK 58에서 가변 글꼴을 지원하면 파일 하나로 바꿀 수 있다.
- **그림자**: `shadow` 토큰은 CSS `box-shadow` 문자열 그대로다. 컴포넌트를 만들 때 실제 기기에서 표시를 확인한다.
- **공통 UI 컴포넌트**: 디자인 시스템 컴포넌트는 웹 React 코드라 그대로 쓸 수 없다. `src/components/ui/`에 React Native로 다시 만든다.
